# Guías Coodescor — Dependencias
#
# Este proyecto está diseñado para funcionar SIN dependencias externas (stdlib-only).
# No es necesario ejecutar `pip install -r requirements.txt`.
#
# La única dependencia OPCIONAL es 'segno' para generar códigos QR SVG
# inline en la vista de detalle de una guía. Si no está instalada, la
# aplicación sigue funcionando y simplemente no muestra el QR.
#
# Para instalar el soporte de QR (opcional):
#   pip install segno>=1.6
