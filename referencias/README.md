# Referencia visual del formato de guía

Esta carpeta está creada únicamente como apoyo visual para futuras modificaciones del aplicativo.

- No forma parte de la lógica del sistema.
- No se usa en la ejecución ni en la base de datos.
- Solo sirve como referencia para comparar el diseño y la estructura del formato de guía.

## Uso recomendado

Guarda aquí cualquier imagen, captura o boceto del formato que quieras emular o adaptar en la interfaz del sistema.

Ejemplos:
- formato de acta de entrega
- diseño de guía impresa
- referencia visual del flujo operativo

## Estructura sugerida

- `guia_formato_referencia.png`  -> imagen principal de referencia
- `observaciones.txt`            -> notas del diseño o cambios que deban hacerse

> Se recomienda mantener esta carpeta limpia y sin afectar la funcionalidad del proyecto.
